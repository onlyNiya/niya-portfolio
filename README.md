# 刘亚怡 Niya — Portfolio

这是刘亚怡 Niya 的个人作品集，采用无依赖的 HTML、CSS 和 JavaScript，可以直接在浏览器中打开 `index.html`。

## 当前结构

- 首页左侧：分行姓名、个人简介下载、可展开的电话/邮箱/小红书入口
- 首页右侧：六个可切换的作品板块
- 项目详情：左侧项目说明，右侧纵向滚动的作品面板
- 支持鼠标滚轮、方向键、触屏滑动和浏览器前进/后退
- 桌面端与移动端自适应

## 已完成的小红书运营板块

- 首页入口使用暗酒红主导、黑色由左下角缓慢过渡的圆角正方形卡片
- 账号总览与主页形象；长截图置于固定窗口内，可独立纵向滚动查看
- 四类内容矩阵与产品内容转译方法合并呈现，四张封面均完整显示并可进入独立案例页
- 四个案例页已接入原文链接、核心数据、内容策略、结构拆解与亮点说明
- vivo X Fold6 商业案例按策略、脚本、拍摄、剪辑、成片、发布与复盘的顺序展开
- 横图与竖图采用统一比例画框，素材默认完整显示，避免裁切
- 增长数据占位与能力总结
- 已接入正式小红书主页链接、真实图片和原始成片

## 已完成的实习经历板块

- 第一层按爱奇艺、UFA、华龙网、歪嘴酒排列四张经历卡片，仅显示时间、公司和岗位
- 四张卡片均可进入独立详情页，并支持浏览器前进、后退与返回原位置
- 爱奇艺详情包含五频道矩阵总览及越站、SHORTS、燃漫、玄漫四组后台数据证据
- 华龙网详情包含端到端采编流程和九篇可跳转的公开图文报道
- UFA 详情呈现赛事内容转化路径与项目影响力；歪嘴酒详情呈现 KOL、用户共创和校园渠道三类工作
- 桌面端和移动端均使用自适应版式，后台截图采用统一比例完整显示

## 增加项目

复制 `app.js` 中 `projects` 数组内任意一个项目对象，修改 `id`、标题、简介、指标和画廊类型即可。每个 `id` 必须保持唯一。
